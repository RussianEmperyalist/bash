# Bash 4All

Интерактивный курс bash для сисадминов и специалистов по ИБ: 16 уроков, учебная консоль, автопроверка заданий.
Прогресс хранится локально в браузере (localStorage).

## Запуск
Достаточно открыть `index.html` в браузере — страницы работают и по двойному щелчку (`file://`), и на хостинге.
Если нужен локальный сервер: `npm start` (откроется http://localhost:8000).

## Публикация на GitHub Pages
1. Загрузите всё содержимое папки в репозиторий (`index.html`, `course.html` и т. д. — в корне; папка `js/bundles` обязательна).
2. Settings → Pages → Deploy from branch → `main` / root.

## Если меняете исходники
Исходники — ES-модули в `js/`, но страницы грузят готовые сборки из `js/bundles/`.
После любых правок в `js/` выполните:

    npm install
    npm run build

## Структура
- `index.html`, `course.html`, `progress.html`, `about.html` — страницы
- `css/` — стили
- `js/course/course-data.js` — содержание уроков
- `js/bash/` — интерпретатор и команды, `js/simulator/` — виртуальная Linux-система
- `js/laboratory/` — терминал и проверка заданий, `js/core/` — состояние и хранилище, `js/pages/` — скрипты страниц
- `js/bundles/` — собранные скрипты (генерируются командой `npm run build`)

## Уроки курса
1. Команды и справка — ls, man, which, type, --help
2. Конвейер и перенаправление вывода — |, >, >>
3. Фильтрация и поиск текста — grep, head, tail, wc
4. Переменные и массивы — VAR=val, arr=(a b c), ${#arr[@]}
5. Файлы и каталоги — touch, mkdir, rm, cp, mv, cat
6. Условия и циклы — if/then/else/fi, for/do/done, while/do/done
7. Поиск по тексту и логам — grep в файлах и каталогах
8. Процессы и службы — ps, kill, systemctl
9. Учётные записи и группы — id, whoami, groups
10. Журналы и события — journalctl, dmesg
11. Ассоциативные массивы — declare -A
12. Функции — name() { ... }, $1, $2
13. Обработка ошибок — $?, set -e, ||
14. Сетевые соединения — ss, ip addr
15. Целостность и хэши — sha256sum, md5sum
16. Поиск секретов в файлах — grep -ri

## Проверка

Запустите тесты командой:

    npm test

Тесты проверяют структуру всех 16 уроков, запуск каждой команды из кнопок примеров и прохождение автопроверки с подсказкой каждого урока. Перед публикацией исходников можно пересобрать файлы командой `npm run build` после установки зависимостей (`npm install`).


## Методика курса

Каждый урок теперь начинается с короткой административной ситуации. Студент сначала понимает, **какую проблему решает**, затем изучает команды и только после этого выполняет лабораторное задание.

Базовый алгоритм курса: **сформулировать проблему → собрать факты → проверить гипотезу → изменить минимум необходимого → проверить результат**. Это специально переносит обучение от запоминания команд к диагностическому мышлению системного администратора.
