Bash 4All

О проекте

Bash 4All — бесплатная обучающая платформа по bash для системных администраторов и специалистов по информационной безопасности.

Как это устроено

  • Консоль в уроках — симулятор: собственный интерпретатор bash и виртуальная Linux-система (процессы, службы, файлы, журналы событий, сеть). Ввод никогда не выполняется как JavaScript и не затрагивает ваш компьютер.
  • Прогресс сохраняется в localStorage браузера. Он не уходит на сервер и не переносится между устройствами и браузерами.
  • Хэш в sha256sum — учебный отпечаток, а не криптографический SHA-256.

Ограничения симулятора

  • Это подмножество bash: некоторые опции и синтаксис могут отличаться от реального Linux-окружения.
  • Команды и данные учебные: настоящие системы устроены сложнее.

Запуск и публикация

  • Страницы используют ES-модули, поэтому локально их нужно открывать через веб-сервер, например python -m http.server, а не двойным щелчком по файлу.
  • Для GitHub Pages загрузите всю папку проекта в репозиторий и включите Pages для ветки main.
